01 / Overview

Why a guarded agent

Under zero trust, a log line is not an instruction and an agent is not an operator. An LLM with tools can be prompt-injected, retry until it costs money, or isolate a host on its own. MILAN assumes those attempts will happen and limits what they can do.

Raw payloads are cleaned before a model sees them. The tools only read. Six tool calls is the limit for one alert. Containment waits for a person, and the decision goes into an append-only log. Each run leaves a trace you can replay.

02 / Pipeline

How the pieces fit

  1. 01

    ingest_and_sanitize

    Secrets and PII are redacted. Injection phrases and delimiter breakouts are flagged. The payload goes inside <untrusted_log_payload> before any model call.

  2. 02

    plan_step

    The graph picks the next query from the evidence gathered so far. It stops planning once the investigation is complete or the cap is reached.

  3. 03

    execute_tool

    Three tools query DuckDB tables for SIEM logs, threat intel, and asset inventory. They use bound parameters and read_only=True, so nothing in a log can change stored data.

  4. 04

    synthesize

    Evidence becomes a Pydantic-validated report with a classification, MITRE technique IDs, indicators, and an evidence summary that can be checked against the tool results.

  5. 05

    hitl_gate

    The compiled LangGraph pauses before this node. requires_hitl cannot be turned off. Actions stay pending until approved; a missing or invalid decision is recorded as rejected.

Every step emits a StepTrace with latency, tokens, fallback source, and redaction counts. Runs and step traces are stored in SQLite at data/milan_audit.db. Human decisions go into an insert-only hitl_audit_log.

04 / Quickstart

Run it locally

No paid services and no keys are needed for the offline pipeline, tests, evaluation, or dashboard.

python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements-dev.txt

python -m pytest -q
python -m evals.run_eval --pace --output-md evals/results.md
streamlit run src/ui/app.py

For LLM enrichment, copy .env.example to .env and add free-tier keys. The router applies gentle pacing, exponential backoff, and fallback to the next provider. Free-tier model names change often, so check them against each provider's current docs.
