Why a guarded agent

Under zero trust, a log line is not an instruction and an agent is not an operator. An LLM with tools can be injected or isolate a host on its own.

MILAN limits the damage: payloads are cleaned, tools only read, six calls is the ceiling, and containment waits for a person.

Run it locally

No paid service and no API key are needed for the offline pipeline, tests, evaluation, or dashboard.

python -m venv .venv
pip install -r requirements-dev.txt
python -m pytest -v
python -m evals.run_eval --pace --output-md evals/results.md
streamlit run src/ui/app.py

Windows: .venv\Scripts\activate. macOS/Linux: source .venv/bin/activate. CLI: triage, batch, replay, metrics, init-db. Add --export-dir for a JSON bundle.

For LLM enrichment, copy .env.example to .env. Local Ollama joins with OLLAMA_ENABLED=true. Check each provider’s model names before use.
